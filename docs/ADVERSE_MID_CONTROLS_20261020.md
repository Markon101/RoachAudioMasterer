# Adverse Mid controls: coherent false edits and assessment units

Source base: `9cd6d56`; same frozen Mid-v3, Euler8 and pinned native binary as the
[coherence experiment](LONG_COHERENCE_RESULTS.md). No learned weights, production
signal path or routing threshold changed. This is development evidence, not final
held-out qualification or a perceptual result.

## Exact short-source reconstruction

`examples/export_mid_controls.rs` calls the actual frozen
`rich_synth::generate_mid_multitrack` and its returned `recipe.damage.apply`.
It loads no model. Seven targets and degraded inputs are preserved as native
float32 WAV and canonical planar little-endian samples, with recipes, file/source/
binary hashes and Git provenance. It rejects final seeds, duplicates, oversized
sets and existing destinations. The optional research tool requires `sha256sum`;
the Rust core gains no new package dependency.

Development seeds: 860003/860015 stopped-mid, 860007/860019 vocal-with-aspiration,
860002 vocal-formant, 860004 silence and 860005 near-silence. Ten regenerated
target/input fingerprints agree with archived identity controls for the five
previously evaluated scenes. The new SHA256 values pin actual regenerated bytes;
historical FNV agreement is not cryptographic authentication of missing old audio.
The two new seed instances are source-only, with no new neural evaluation.

Each scene is only 16384 samples (0.3413 seconds). They are not long-coherence
tests and were not tiled. The source bundle has no component stems. In particular,
both vocal families already add aspiration before formant filtering and `tanh`.
Family 3 also changes seed and room processing; its name does not make it an
aspiration-only ablation. Any future aspiration-off subtraction must preserve RNG
draws and be labeled a nonlinear counterfactual, rather than an additive stem.

Archived native L/R summed missing-band error powers for stopped seed 860003:

| Control/method | Absolute error power |
| --- | ---: |
| Identity | 2.03e-16 |
| Deterministic harmonic prior | 6.13090e-6 |
| Euler8 | 5.72036e-6 |

Target missing-band power is about 1.19e-16, so relative NMSE remains undefined.
Most false addition is already present in the harmonic prior; it cannot be
attributed entirely to the neural noise term. Euler8 reduces it slightly here.

For vocal seed 860007, L/R energy-pooled NMSE is 0.79072 identity, 3.95453 prior,
3.68661 Euler8. The report also preserves per-channel values and means; these are
different aggregations. New float64 Fourier recomputation splits Euler8 error
algebraically into magnitude error and a phase term, with 34.9% assigned to the
latter. This identity does not establish that stochastic aspiration phase is
recoverable, or that magnitude matching establishes perceptual quality.

## Continuous stopped-mid negative

The existing continuous 32-second source recipe at seed 881002 is globally
low-passed at 1200 Hz with a 100 Hz transition and power 3, then cast once to
float32. There is no subsequent normalization. The input is an exact target copy:
there is no manufactured damage to repair. This is a spectral stopped-mid source,
not a temporal silence interval. Its full-source 1500–8000 Hz power is at most
2.565e-18, below the frozen 1e-14 null floor. Cropped FFT leakage is not used to
certify that null.

The same two 26-second, hop-aligned views, eight-second/two-second WOLA layout,
13-second common interior and four arms are used. Both excitation modes use the
same pinned OpenCL binary. Separate whole-clip projection uses the actual Rust
implementation and observed input, with no target selection or normalization.

| Arm | False residual RMS, view0 / view3 | Common-interior layout RMS |
| --- | ---: | ---: |
| Restart + projection | 0.001388 / 0.001351 | 0.001196677 |
| Continuous + projection | 0.001403 / 0.001366 | 0.000044051 |

Layout RMS falls 96.319%; continuous overlap cosine is about 0.980–0.985 versus
0.693–0.826 for restart. False residual RMS rises 1.141–1.148%, passing the frozen
10% growth limit. All whole-view protected-band gates pass; raw Python/native
WOLA maximum difference stays below 6.6e-8.

**Passing growth and continuity gates does not make the residual correct.** Both
methods add about 1.02–1.03% of input RMS to a target that is already present
exactly; instantaneous deviations reach about 0.0372. Identity has zero error.
This directly rejects continuity as a sufficient proxy for cleaner reconstruction.
It does not prove these small edits are audible or describe automatic activation.
No additional final-mastering or real-recording claim is made for this negative.

## Automatic policy qualification and a measurement defect

Standalone native `assess` and its base tuning card give Mid authority zero for
both the long stopped source and short stopped seed 860003. The aspiration case
gets 0.6. These are input-only/base recommendations, before musical-intent/manual
overrides; they are not end-to-end activation measurements. The forced-head
negative must not be presented as a production routing regression.

The assessment probe exposes a separate unit error. Band fields named `*_dbfs`
average raw, unnormalized squared STFT coefficients over frames and bins. They
are not physical integrated band RMS dBFS. With L=R=0.1·sin(2π·281.25·t), the
orthonormal mid-channel RMS is -20 dBFS, while `low_mid_energy_dbfs` reports
+25.132885. At amplitudes 0.001 and 0.00001, the physical values are -60/-100
dBFS and legacy values -14.867173/-54.86702. The approximately 45.13 dB offset
is specific to this FFT, window, band width and source, not a universal correction.

Absolute sub/Mid authority comparisons use these legacy scales. Relative cutoff
comparisons also use per-bin rather than integrated band powers. This is a
diagnostic correctness issue, not permission to subtract one constant and retune
the production controller. A calibrated, independently tested observer and
explicit legacy-unit labels should come before any routing change. Quiet and
silence controls require separate treatment. The current champion stays frozen.
